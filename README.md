# Ground Shift — watching land change with NISAR radar

NASA Space Apps Challenge 2026 · Challenge: **Dancing with the SARs** · Team: CIELIEN

> Work in progress during the hackathon (Nov 14–15, 2026 KST).

## What it is
An interactive web map that uses NISAR L-band radar (L2 GCOV backscatter, HH and HV) to show how large human construction projects reshape natural land over one year.

## Data
- NISAR L2 GCOV (BETA, PROVISIONAL, VALIDATED collections), NASA/ASF DAAC — via ASF Search (`asf_search`) and Earthdata Login.

## Use of Super Intelligence (SI)
Portions of the code and English text were drafted with SI assistance (Claude, ChatGPT) and reviewed by the team. All maps and radar images come from real NISAR data; no SI-generated imagery is used in the data views.
